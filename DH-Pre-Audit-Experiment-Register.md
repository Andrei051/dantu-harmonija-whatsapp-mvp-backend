## EXP-001 — Implant pain / recovery question

| Field | Value |
|---|---|
| Working title | Ar skauda dantų implantavimas? / skausmas po implantacijos |
| Status | Complete |
| Result | **PASS** (small-scale validation) |
| Timing | Pre-audit programme |

### What happened
1. Hypothesis identified
2. Page created
3. Indexed by Google
4. Query mapping observed
5. Performance measured
6. Learning captured

### Outcome checklist
| Metric | Outcome |
|---|---|
| Indexation | Success |
| Query alignment | Success |
| Relevant clicks | Success |
| Positioning | Reasonable (~14–15 reported) |
| Behavioural signal | Confirmed |

### Measured signal
From GSC Pages export (Web · Last 12 months, captured 2026-07-14):

`/naudinga/skausmas-po-dantu-implantacijos-gijimas-ir-galimos-komplikacijos/`  
≈ **4,955 impressions · 298 clicks**

### Defensible finding
The clinic can successfully capture a **patient decision-stage question** when the question aligns with real search behaviour.

### What this does *not* prove
- Content expansion works broadly
- All FAQ pages will perform
- Local GBP demand for implants rises

### Fit to post-audit discovery model
Maps to **Implants → research-heavy discovery** (pain, healing, aftercare, complications) — consistent with Phase 3 Session 2 journey-stage finding.
